# AscentAgain Web Application 🌟

Welcome to AscentAgain, a web application developed for HackViolet's Hackathon. Our website is specifically aimed at supporting women in distress by providing answers to questions like "What next?", "Where do I go from here on?", "How do I cope with this colossal amount of stress?", and "How do I take care of myself and my family now?"

## Features and Services 💡

### 1. Job Search 🧑‍💼
Helping women find suitable job opportunities to regain their financial independence.

### 2. Therapy Services 💬
Connecting users with therapists to help them cope with stress and emotional challenges.

### 3. Community Forum 🗣️
A safe space for women to discuss issues, share stories, and support each other.

### 4. Empowerment Information 📜
Providing general yet lesser-known facts about female empowerment laws in India.

### 5. Helpline Numbers ☎️
A comprehensive list of women helpline numbers for immediate assistance.

### 6. Real-Time Data for Four Cities 🌍
Our services cater to the cities of Mumbai, Delhi, Kolkata, and Bangalore, using real-time data for relevant and up-to-date information.

## Getting Started 🚀

To get started with the AscentAgain web application, follow these steps:

### Prerequisites

- Ensure you have a web server and a database server installed (e.g., XAMPP, WAMP).
- Download the database file `hackvioletdatabase.sql`.

### Installation

1. Clone the Repository: Clone the repository from your version control system and navigate to the project directory.

2. Set Up the Database: Import the `hackvioletdatabase.sql` file into your database server. Configure your database connection settings in the web application's configuration files.

3. Run the Application: Start your web server. Open your web browser and navigate to `http://localhost/AscentAgain`.
